# Briefing — Diagnóstico para oficinas

Fonte: laudo `docs/laudo-quiz-diagnostico-oficinas.docx`.

## Entrega

LP de tráfego (Hostinger) + quiz diagnóstico com PDF (Vercel).

## Funil

1. LP — oferta do diagnóstico
2. Lead obrigatório — empresa, CNPJ, fundação, cidade, nome, cargo, idade, gênero, WhatsApp, e-mail
3. 19 perguntas em Financeiro, Operação, Gestão, Comercial
4. Resultado + PDF + CTA Consultoria Gerencial (e Tempário se P15 = Não)

## Motor (não é formulário simples)

| Cruzamento | Regra |
|------------|--------|
| P1 × P2 × P7 | Custo fixo / faturamento só se vende peças e serviços. Ideal 25–32% |
| P3 | ≥100 Bom · 60–99 Mediano · <60 Atenção + exceções 400% / 30% |
| P4 × P5 | Caixa saudável = 2 meses+ e sem antecipação (~5% do país) |
| P5 × fundação | Antecipar + até 5 anos = transição; +5 anos = reduzir |
| P2 × P6 × P8 | `70% × 176 × hora × mecânicos / 0,40` vs faturamento informado |
| P1 × P6 × P8 | Custo da hora = fixo ÷ (176 × mecânicos); hora mínima = ×2 |
| P6 × P9 | 1,5 elevador por mecânico |
| P13 | Sim (dono é gestor de pátio) = atenção |
